# Heart Disease Prediction Using Machine Learning

## Overview

This project investigates machine learning approaches for predicting
heart disease using the Cleveland subset of the UCI Heart Disease dataset.

## Dataset

The dataset contains 303 observations and 13 predictor variables.

Source:
UCI Machine Learning Repository — Heart Disease Dataset

https://archive.ics.uci.edu/dataset/45/heart+disease

## Project Structure

- `notebooks/01_data_validation.ipynb` — Dataset validation
- `notebooks/02_eda.ipynb` — Exploratory data analysis
- `notebooks/03_preprocessing.ipynb` — Data preprocessing
- `src/` — Source code
- `results/` — Experimental results
- `docs/` — Project documentation

## Methodology

The project includes:

1. Dataset validation
2. Exploratory data analysis
3. Statistical analysis
4. Data preprocessing
5. Machine learning
6. Model evaluation
7. Comparison with related research

## Evaluation Metrics

The models will be evaluated using:

- Accuracy
- Precision
- Recall/Sensitivity
- Specificity
- F1-score
- ROC-AUC
- Confusion matrix

## Reproducibility

Random seeds and preprocessing procedures are documented
to support reproducibility.
